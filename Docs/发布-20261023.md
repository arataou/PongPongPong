# 碰碰球 2026年10月23日发布说明

本版包含经过试玩确认的两层透明菜单：主界面五个纵向入口，开始游戏进入对局设置，确认后进入游戏；背景及标题素材保持原样，无效地图入口移除。

## 运行与操作

Windows 64位，解压完整目录后启动 `Windows/PongPongPong.exe`，保持exe、UnityPlayer.dll与数据目录相邻，不单独复制exe。

主界面点击开始游戏，选择对战或合作、2人或3人及AI难度，再点击开始对局。对局设置可返回或按Esc回首页；操作说明、设置、战绩沿用原功能。

- 玩家1：W/A/S/D；玩家2：方向键；玩家3：I/J/K/L。
- Esc暂停；结算后R重开、M回菜单。
- 整颗球完全出界才淘汰；无敌可以穿球，仍会出界。

## 构建与源码

构建环境为当前已使用的Unity 6000.3.23f1，场景顺序为MainMenu、SampleScene，目标为Windows x86_64。工程同时保留既有URP、字体、包与ProjectSettings迁移结果，使发布源码与本机运行环境一致；这些迁移不是本轮新增玩法。

`Assets/Editor/CompetitionReleaseBuilder.cs`通过本机Editor构建。请求配置存放在忽略的 `Library/CompetitionReleaseBuild.request`，JSON包含输出exe完整路径和sourceCommit；结果记录在 `Library/CompetitionReleaseBuild.result.json`。构建时仅将产品显示名设为PongPongPong，结束后恢复Editor原设置。构建文件不提交进源码仓库，精确提交和文件校验见交付包内发布清单。

菜单运行检查已覆盖两层导航、模式/人数/难度选择、原功能面板返回和进入SampleScene，实际推进41帧；界面已按1920×1080和1280×800检查，用户已确认本版。具体构建结果以本次BuildReport及发布清单为准。
