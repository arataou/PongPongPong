## 3. AI 难度三档

### 3.1 用途

主菜单选难度后,通过 `GameSession.Difficulty` 透传给 AI 系统,影响**首次出现时间 / 出现间隔 / 移动速度 / 质量**四个维度。

### 3.2 关键文件

- `AIDifficulty.cs:1` — `AIDifficulty` 枚举 + `DifficultyProfile` 结构
- `GameSession.cs:14` — `Difficulty` 属性 + PlayerPrefs 持久化
- `AISpawner.cs:32` — Start 时读 `Profile.firstSpawnDelay` / `spawnInterval`
- `AIController.cs:17` — Awake 时读 `speedMul`(每帧用) + `massMul`(只 Awake 一次)
- `DifficultySelector.cs:1` — 三按钮 UI 控件

### 3.3 数据

```
Easy   : firstDelay=90s, interval=15s, speedMul=0.7x, massMul=0.7x
Normal : firstDelay=60s, interval=10s, speedMul=1.0x, massMul=1.0x
Hard   : firstDelay=30s, interval=5s,  speedMul=1.4x, massMul=1.3x
```

### 3.4 如何扩展

**加第 4 档(比如 "地狱"):**
1. `AIDifficulty.cs:3` 的 enum 加 `Hellish`
2. `DifficultyProfile.Get()` switch 加分支返回新参数
3. `DifficultyProfile.Label()` 加文字
4. `DifficultySelector.cs` 加 `hellishButton` 字段 + Set/Paint 一行
5. 主菜单 UI 加一个按钮

**改难度影响的维度**(比如想加 "AI 数量上限上调"):
1. `DifficultyProfile` 加 `int maxConcurrent` 字段
2. 三档参数填值
3. `AISpawner.cs:25` `coopMaxConcurrent` 改为读 `GameSession.Profile.maxConcurrent`

**让 PvP 也吃难度**(目前 PvP 模式下 spawnInterval 是按难度的,已生效;若想 PvP 不吃难度):
- `AISpawner.cs:33` Start() 里加 `if (mode == PvP) { firstSpawnDelay = 60f; spawnInterval = 10f; }` 覆盖。

## 4. 合作模式 (COOP)

### 4.1 用途

把游戏从 PvP 切到 PvE 生存战:玩家 vs AI,所有玩家死亡才结算,记录存活时长。

### 4.2 关键文件

- `GameSession.cs` — `Mode` 字段(GameMode.PvP / Coop)
- `MatchManager.cs:51` — `CheckEnd()` 按 Mode 路由(COOP 时只在 alive==0 结束)
- `MatchManager.cs:33` — `Update()` 累加 `ElapsedTime`
- `AISpawner.cs:54` — COOP 模式每 30s 把间隔减半 + 并发上限 8
- `HudController.cs:55` — COOP HUD 显示存活计时
- `EndScreen.cs:60` — COOP 结算显示存活时长 + 历史
- `MatchHistory.cs:24` — `GetCoopBest(playerCount)` / `SetCoopBest(...)`

### 4.3 规则

- **玩家相互可推**(开放无墙,推队友出界算队友先死)
- **AI 越打越多越快**:每 30s `spawnInterval *= 0.5`,下限 1s,并发上限 8
- **记录维度**:仅 **变态难度** 下记录最长存活;按人数分 2P / 3P 两条记录(`PPP_COOP_BEST_2P_HARD` / `PPP_COOP_BEST_3P_HARD`)
- 非变态难度下游戏可玩但不进排行榜

### 4.4 如何扩展

**加更多 COOP 关卡(如限时 / 杀够 N 个 AI 才赢):**
1. `GameSession` 加 `CoopSubMode` 字段
2. `MatchManager.CheckEnd()` 按子模式路由不同结束条件
3. `MatchHistory` 加对应记录键

**调整 AI 缩放节奏**(`AISpawner.cs:14`):
- `coopHalveEvery` — 每多少秒减半,改大 = 更慢加码
- `coopMinInterval` — 间隔下限
- `coopMaxConcurrent` — 并发上限

**改记录维度**(比如想分难度记录):
- `MatchHistory.GetCoopBest` / `SetCoopBest` 加 `AIDifficulty` 参数
- `MatchManager.RecordCoopResult()` 不再过滤 Hard
- `HistoryPanel.Refresh()` 显示 3 档 × 2 人数 = 6 条

## 5. 音效系统

### 5.1 用途

提供 BGM 循环 + SFX 池(避免单帧多次触发 PlayOneShot 卡顿)。所有 SFX 走同一个 `PlaySfx(clip, volumeScale)` 入口。

### 5.2 关键文件

- `AudioManager.cs:1` — 单例(DontDestroyOnLoad)
- `UIClickSound.cs:1` — Button onClick 自动播 UI 点击
- 触发点:
  - `PlayerBase.cs:172` OnCollisionEnter2D 撞击
  - `PlayerBase.cs:96` OnDestroy 死亡
  - `BuffPickup.cs:13` 拾取
  - `PlayerBase.cs:161` Shockwave 拾取瞬间

### 5.3 数据流

```
GameSession.BgmVolume/SfxVolume (setter)
        │
        ▼
GameSession.ApplyAudio()
        │
        ▼
AudioManager.ApplyVolumes(bgm, sfx)
        │
        ├──> BGM AudioSource.volume = bgm
        └──> PlayOneShot 时乘以 sfx
```

### 5.4 如何扩展

**加新 SFX**:
1. `AudioManager.cs:18` 增字段 `public AudioClip sfxNewThing;`
2. 在 Inspector 拖 AudioClip
3. 触发点调 `AudioManager.Instance.PlaySfx(AudioManager.Instance.sfxNewThing)`

**接 BGM 切换**:
- 进 SampleScene 时:在场景某个启动脚本(`ArenaLoader.Awake()` 末尾或独立 `GameBootstrap`)调 `AudioManager.Instance.PlayGameBgm()`
- 回主菜单时:`MainMenuController.Start()` 调 `AudioManager.Instance.PlayMenuBgm()`
- 这两行**目前未在代码里加**,因为不知道你想不想要——你想接的话只加这两行即可。

**改撞击音阈值**(`AudioManager.cs:23` `impactHardThreshold`):
- 默认 6,relativeVelocity ≥ 6 用 hard 否则 soft
- 改大 → 只有很猛的撞击才播 hard

**SFX 限流**(`AudioManager.cs:25` `sfxMinInterval`):
- 默认 0.02s,防一帧内 N 个撞击同时触发刺耳
- 改 0 = 不限流,改大 = 更克制

## 6. 战绩系统

### 6.1 用途

PvP 累加 P1/P2/P3 胜场 + 平局数 + 总场数。COOP 仅在变态难度记录 2P / 3P 最长存活。

### 6.2 关键文件

- `MatchHistory.cs:1` — 静态类,纯 PlayerPrefs 读写
- `MatchManager.cs:76` — 结束时调 `MatchHistory.RecordPvP` 或 `RecordCoopResult` (后者走 MatchManager 内 `MatchHistory.SetCoopBest`)
- `HistoryPanel.cs:1` — UI 展示组件

### 6.3 PlayerPrefs 键

| 键 | 类型 | 内容 |
|---|---|---|
| `PPP_PVP_WINS_P1` | int | P1 累计胜场 |
| `PPP_PVP_WINS_P2` | int | P2 累计胜场 |
| `PPP_PVP_WINS_P3` | int | P3 累计胜场 |
| `PPP_PVP_DRAWS` | int | 平局数 |
| `PPP_PVP_TOTAL` | int | PvP 总场数 |
| `PPP_COOP_BEST_2P_HARD` | float | 2P 变态最长存活(秒) |
| `PPP_COOP_BEST_3P_HARD` | float | 3P 变态最长存活(秒) |

### 6.4 如何扩展

**加新统计维度**(如 "P1 击杀 AI 数"):

## 7. Buff 扩展

### 7.1 已有 Buff

| Buff | 持续 | 效果 |
|---|---|---|
| Speed | 5s | 速度 / 加速度 ×1.5 |
| Heavy | 5s | 质量 ×3 |
| Reverse | 5s | 输入反向 |
| **Invincible**(新) | 3s | 与其他球/AI 互不碰撞(穿过对方),仍能吃 buff、仍能被冲击波推。**注意:出界依旧死亡**(BoundsKiller 走位置判断,不豁免)。光环显示 |
| **Shockwave**(新) | 瞬发 | 拾取瞬间对半径 4.5 内所有 Rigidbody2D 施加 12 力 |

> **无敌的"穿球"是怎么做到的**:用 Layer 矩阵实现。`PlayerBase` 在 `Awake` 把 `gameObject.layer = "Player"`,触发无敌时切到 `"InvinciblePlayer"`,过期切回。`Physics2D.IgnoreLayerCollision(InvinciblePlayer, Player, true)` 在第一次球初始化时一次性配好。AIController 也会把自己设到 Player layer。Layer 6/7 在 TagManager 已定义,**不要重命名**。BuffPickup 是 trigger,不受 Layer 矩阵影响,所以无敌期间还能继续吃 buff。

### 7.2 关键文件

- `PlayerBase.cs:7` — `PickupBuff` Flags 枚举(必须保持 1/2/4/8/16 等 2 的幂)
- `PlayerBase.cs:131` — `ApplyPickupBuff()` 路由
- `PlayerBase.cs:152` — `TriggerShockwave()` 实现
- `BuffPickupSpawner.cs:14` — `BuffPool` 决定哪些 buff 会被刷出
- `BuffPickupSpawner.cs:76` — `ColorFor()` buff → 颜色映射(策划/美术调色入口)
- `BoundsKiller.cs` — 出界直接销毁,不分玩家是否无敌

### 7.3 如何扩展

**加新 buff**(模板:加个"小球分裂"):
1. `PlayerBase.cs:11` `PickupBuff` enum 加 `Clone = 32`
2. 决定是**持续 buff**(需要 timer)还是**瞬发**(只在 ApplyPickupBuff 里执行)
3. 持续 buff:
   - 加私有 `float cloneTimer;`
   - `TickBuffTimers()` 加分支
   - `ApplyPickupBuff()` 启动 timer
   - 视觉:加 `cloneAura` 字段(可选)
4. 瞬发 buff:
   - 在 `ApplyPickupBuff()` 开头 `if ((buff & PickupBuff.Clone) != 0) TriggerClone();`
   - 写 `void TriggerClone()` 实现
   - 注意把 Clone 从 `activeBuffs |=` 屏蔽(`& ~PickupBuff.Clone`)避免误置位
5. `BuffPickupSpawner.cs:14` `BuffPool` 数组加 `PickupBuff.Clone`
6. `BuffPickupSpawner.cs:76` `ColorFor()` 加分支返回颜色

**调 BuffPool 概率**:目前是等概率随机,如果想加权:
- 把 `BuffPool` 改成 `[(buff, weight)]` 列表
- 用累加权重抽样

**禁掉某个 buff**:从 `BuffPool` 数组里删掉即可,枚举不必删。

- `ArenaBounds.cs:33` `Apply(preset)` — Shrinker 通过临时 ScriptableObject 复用同一入口

### 8.3 接入 ArenaPreset

`ObstacleMover` 是给 **障碍物 Prefab**用的,做法:

1. 创建一个 Cube/Sprite 节点,加 `BoxCollider2D` + `Rigidbody2D` (Body Type=Kinematic)
2. 加 `ObstacleMover` 组件
3. 拖成 Prefab
4. 在 `ArenaPreset` 的 `Obstacles` 列表里加一条,Prefab 选刚做的,Position 设为初始位置(`ObstacleMover.Awake` 会以此为中心)

`ArenaShrinker` 是 **场景级**组件(不是单个 obstacle),直接挂在场景里某个空 GameObject 上,只挂在你想"毒圈"化的场景里。

### 8.4 如何扩展

**加新障碍物行为**(如旋转 / 周期出现):
1. 新建 `ObstacleRotator.cs`,挂 Rigidbody2D Kinematic,FixedUpdate 调 `rb.MoveRotation(angle)`
2. 做 Prefab,塞 ArenaPreset

**让 ArenaShrinker 在 COOP 模式下才启用**:
- `ArenaShrinker.Start()` 加 `if (GameSession.Instance == null || GameSession.Instance.Mode != GameMode.Coop) { enabled = false; return; }`

**让收缩跟 AI 节奏挂钩**(比如每来一波 AI 缩一次):
- 移除当前的 `Update` 内时间累加
- 改在 `AISpawner.SpawnOne` 末尾调 `ArenaShrinker.Instance.ShrinkOnce()`

### 9.3 接入

- **GameFeel**:已有的 GameFeel GameObject,新增字段 `impactParticle` 拖一个场景里的 ParticleSystem 引用
- **BallTrail**:挂到 P1 / P2 / P3 球上,无字段必填(`trailMaterial` 留空会用 Sprites/Default)

### 9.4 如何扩展

**加屏幕闪光**(命中瞬间全屏亮):
1. 在 Canvas 上加个全屏白 Image,默认 alpha=0
2. `GameFeel` 加 `[SerializeField] Image flashImage; [SerializeField] float flashAmp = 0.3f;`
3. `PlayImpact` 中 `if (vel > 8) flashImage.color = new Color(1,1,1,flashAmp);`
4. Update 中 `flashImage.color.a = Mathf.MoveTowards(..., 0, decayRate*Time.deltaTime)`

**加击杀爆裂粒子**(球死亡时):
- `PlayerBase.OnDestroy` 调 `GameFeel.Instance.PlayImpact(transform.position, 15f)`(借用现有粒子)
- 或独立 `PlayDeathBurst(pos, color)` 用更显著的粒子

**Trail 加渐变色**(随状态变):
- `BallTrail.RefreshColor()` 已经按 sprite.color 走,所以如果你给 Fast 状态加变色,trail 会跟着变
- 想要 Fast 时 trail 变白:Refresh 中 `if (player.State == BallState.Fast) c = Color.white;`
