# 编辑器对接清单

代码已写完，下面是 **必须在 Unity 编辑器里手动完成** 的事项。按顺序做就能跑起来。

---

## 0. 脚本已生成

`Assets/LogicScripts/` 下新增了 8 个脚本：

- `ArenaBounds.cs` — 场地范围单例
- `BoundsKiller.cs` — 出界即销毁
- `MatchManager.cs` — 玩家计数 + 胜负判定
- `StateRouletteController.cs` — 5s 状态轮换
- `AIController.cs` — AI 追击逻辑
- `AISpawner.cs` — AI 生成器
- `HudController.cs` — 顶部双倒计时
- `EndScreen.cs` — 胜负面板
- `PauseMenu.cs` — ESC 暂停面板

`PlayerBase.cs` 也改了：移除了 Clamp 和 boundsMin/Max 字段，加了 `ApplyState`、`PlayerIndex`、`fastStateOutline`。

## 2. 修整两个玩家球（P1 / P2）

每个玩家球的 GameObject 上需要：

- ✅ `Rigidbody2D`（已有；`Gravity Scale=0`，`Linear Damping` 建议 0~1）
- ✅ `CircleCollider2D`（PlayerBase 现在 `[RequireComponent]`，没有的话 Unity 会自动加）
- ✅ `PlayerController`（P1）或 `Player2Controller`（P2）
- 🆕 `BoundsKiller`（**新加**，用 Add Component 加上）

在 PlayerController/Player2Controller 的 Inspector 里：
- `Base Move Speed` = 5
- `Base Acceleration` = 25
- `Base Mass` = 1
- `Fast State Outline` 字段：**留空也能跑**，仅 Fast 状态没视觉描边。如果想做描边：在玩家球下创建一个子 GameObject 命名 `FastOutline`，加一个比父球稍大的白色 sprite（缩放 1.1 左右），默认禁用，然后拖到这个字段。

颜色：P1 蓝、P2 黄（修改 SpriteRenderer.Color）。

## 3. 创建 AI 预制体

1. 复制一个玩家球作为模板（Hierarchy 里 Ctrl+D），命名 `AIBall`
2. 移除：`PlayerController` / `Player2Controller`
3. 添加：`AIController`
4. 保留：`Rigidbody2D`、`CircleCollider2D`、`BoundsKiller`
5. Inspector 配置：
   - SpriteRenderer.Color = 红
   - `Transform.localScale` = (1.5, 1.5, 1.5)
   - `Rigidbody2D.Mass` = **6**
   - `AIController.MoveSpeed` = 4，`Acceleration` = 25
6. 把 `AIBall` 拖进 `Assets/` 某文件夹（如 `Assets/Prefabs/`，需要先创建）变成 Prefab
7. 删除场景中的 `AIBall` 实例
8. 把 Prefab 拖到 `AISpawner` 的 `Ai Prefab` 字段

## 4. UI Canvas

Hierarchy 右键 → UI → Canvas（自动创建 Canvas + EventSystem）。Canvas 设为 `Screen Space - Overlay`。

在 Canvas 下创建以下结构：

```
Canvas
├── HUD
│   ├── StateLabel (Text)         ← 顶部中央，大字号（如 48）
│   └── AILabel    (Text)         ← StateLabel 下方，小字号（如 24）
├── EndScreenPanel  (Panel,默认禁用)
│   ├── ResultText  (Text)        ← 大字"P1 胜/P2 胜/平局"
│   ├── RestartButton (Button)    ← 文字"重开"
│   └── QuitButton    (Button)    ← 文字"退出"
└── PauseMenuPanel  (Panel,默认禁用)
    ├── ResumeButton   (Button)   ← 文字"继续"
    ├── RestartButton2 (Button)   ← 文字"重开"
    └── QuitButton2    (Button)   ← 文字"退出"
```

> Tip：默认禁用 = 在 Inspector 顶部把那个勾去掉。运行时由脚本控制显隐。

然后创建 3 个空 GameObject 在 Canvas 外（场景根级），分别挂：

| GameObject | 挂脚本 | Inspector 拖拽 |
|---|---|---|
| `HudController` | `HudController` | StateLabel / AILabel |
| `EndScreen` | `EndScreen` | EndScreenPanel / ResultText / RestartButton / QuitButton |
| `PauseMenu` | `PauseMenu` | PauseMenuPanel / ResumeButton / RestartButton2 / QuitButton2 |

## 6. 验收清单

按 Play 后应该看到：
- [ ] 场景里有青色 Gizmo 矩形（仅编辑器可见，标记场地）
- [ ] 屏幕顶部"5 秒后切换状态"+"60 秒后 AI"
- [ ] 两个球可以分别用 WASD / 方向键 控制移动
- [ ] 把对方挤出场地边界 → 该球消失，剩下的球判胜，弹面板，全场冻结
- [ ] 每 5s 两个球各自随机变成 加速/变大/变小（视觉上颜色或大小变）
- [ ] 第 60 秒第一只红色 AI 出现，之前 3s 倒计时数字闪红
- [ ] 此后每 10s 又一只 AI 出现
- [ ] AI 撞玩家把玩家挤出界 → 玩家死。两个玩家都死 → 平局
- [ ] ESC 暂停弹菜单

## 7. 预期问题排查

**没有 EventSystem，按钮点不动**：UI Canvas 创建时 Unity 通常会自动加 EventSystem。如果没有，Hierarchy → Create → UI → Event System。

**TextMeshPro 替换 Text**：脚本用了 `UnityEngine.UI.Text`（Legacy）。若想用 TMP，把脚本里 `using UnityEngine.UI;` 改 `using TMPro;`，`Text` 改 `TMP_Text` 即可。

**球开始后立刻消失**：可能玩家球放在了场地外。检查初始位置是否在 ArenaBounds 的 min/max 范围内，且球半径×scale 没有超过边界。

**AI 不追玩家**：检查 AISpawner 的 `Ai Prefab` 字段是否赋值。也检查 AI 预制体上 `AIController` 是否挂上了。

**变大/变小时撞墙穿模**：理论上没有墙（已拆 Clamp）。如果你额外加了视觉墙的 Collider，AI/玩家会被卡住。先不加墙，靠 `BoundsKiller` 处理出界即可。
