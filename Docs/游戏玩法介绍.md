# 碰碰球 · 游戏玩法介绍

更新日期：2026-10-26。

**在没有围墙的场地里，把对手撞出去，或和队友一起撑过 AI 球的追击。** 游戏支持 2～3 人共用键盘、本地同屏。

## 开始与操作

首页点击开始游戏，进入对局设置，选择模式、人数与 AI 难度，再开始对局。当前没有地图选择入口。

| 操作 | 按键 |
|---|---|
| P1 移动 | W / A / S / D |
| P2 移动 | 方向键 |
| P3 移动 | I / J / K / L |
| 暂停／继续 | Esc |
| 结算后重开 | R |
| 结算后回主菜单 | M |

暂停面板也可重开或返回主菜单；对局设置按 Esc 返回首页。

## 模式与淘汰

- **PvP 对战**：互相推挤，最后存活的玩家获胜；AI 是干扰者，不计入胜者。
- **合作生存**：全队对抗 AI，以存活时间为成绩，所有玩家淘汰才结束。仅最高难度（“变态”）保存纪录，两人和三人组分开记录。
- **整球出界**：完全越过任一边界才淘汰，半个球越界仍可能救回；无敌也遵守此规则。

当前逐个处理淘汰事件，首次满足结算条件即锁定结果，不保证同时出界一定判平。场地含随时间收缩机制，节奏由场景配置决定。

## 随机状态与道具

轮盘给每名存活玩家各自随机分配加速、变大或变小，状态互相替换，AI 不参与。当前场景基础轮盘间隔为 2 秒，合作模式另乘难度节奏倍率。

| 状态 | 基础效果 |
|---|---|
| 加速 | 速度与加速度 ×2 |
| 变大 | 体积 ×1.6，质量 ×2.56 |
| 变小 | 体积 ×0.6，质量 ×0.36 |

道具出现前有半透明预告，仅玩家能拾取，可与轮盘状态组合；持续型道具重复拾取刷新计时。

| 道具 | 效果 |
|---|---|
| 加速 | 短时提高速度与加速度 |
| 变重 | 短时增加质量 |
| 反向 | 短时反转操作方向 |
| 无敌 | 短时穿过其他球，包括 AI；仍可能出界 |
| 冲击波 | 立即向四周推开球体，距离与目标质量影响击退 |

状态倍率为代码默认值，场景／预制体中的 Inspector 配置可覆盖默认值。

## AI 压力与难度

AI 从边缘生成，追击最近的存活玩家，不拾取道具、不参与轮盘。难度同时影响速度与质量。

| 难度 | PvP 首只 AI 延迟 | 基础后续生成间隔 |
|---|---|---|
| 菜（Easy） | 90 秒 | 15 秒 |
| 普通（Normal） | 60 秒 | 10 秒 |
| 变态（Hard） | 30 秒 | 5 秒 |

合作模式约 1 秒后开始生成 AI，之后每 30 秒将间隔减半，最短 1 秒，同屏最多 8 只；淘汰后在后续生成时机补充。合作难度还影响轮盘与道具间隔，倍率越小，切换与生成越频繁。

难度选择会影响 AI 的出现节奏和强度，对战模式也会读取所选难度。

## 上手提示

保留回到场地中心的空间，留意状态切换；变重时可正面推挤，变小时更需控制惯性。无敌适合穿过包围圈，冲击波可以打开撤退路线。战绩面板展示本机累计统计与最佳成绩，不是逐局记录。
