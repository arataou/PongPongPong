## 实现的交互过程
- **PvP 模式**:2-3 名玩家本地同屏,把对手推出场地者胜
  - P1 = `WASD` / P2 = `↑↓←→` / P3 = `IJKL`
  - 每隔几秒玩家属性随机切换(加速 / 变大 / 变小)
  - 1 分钟后开始刷 AI 球追击玩家
- **COOP 模式**:2 名玩家联手对抗无限 AI 海,按难度三档(Easy / Normal / Hard)联动节奏
- **5 种 Buff**:加速 / 变重 / 反向 / 无敌 / 冲击波,场地随机刷新
- **通用**:`Esc` 暂停 / `R` 重开 / 完全出界判定 / BO1 决胜
