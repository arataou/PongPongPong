# 碰碰球 期中作业版

## 游戏概述

本地双人 PvP +「后期 AI 干扰」的小型生存竞速游戏。

- 双人各操控一颗小球，互相挤撞
- **整球被推出场地边界**即淘汰
- 每 5s 全场状态轮换（加速 / 变大 / 变小），不断改变战术
- 第 60s 起，每 10s 生成一只 AI 球追击最近玩家，永不停止
- 谁先把对方推下场，谁就赢；都被 AI 挤死则平局

---

## 一、玩家与边界

| 项 | 决策 |
|---|---|
| 场地形状 | 矩形（沿用 `boundsMin`/`boundsMax`） |
| 物理边界 | 无墙——越过即可继续飞出（**移除 `PlayerBase.cs:36-38` 的 Clamp**） |
| 死亡判定 | 球**整体**出界：球心 ± 当前实际半径 完全越过 boundsMin/Max 任一轴 |
| 半径来源 | `CircleCollider2D.radius * lossyScale`（适配变大变小） |
| 边缘提示 | 无 UI/视觉提示 |
| 死亡后处理 | 球完全销毁（`Destroy(gameObject)`） |

---

## 二、状态机制（每 5s 切换一次）

| 项 | 决策 |
|---|---|
| 切换节奏 | 每 5s 切换一次（与计时器节奏对齐） |
| 状态种类 | 加速 / 变大 / 变小（三选一，等概率） |
| 作用对象 | P1、P2 各自独立随机抽 |
| 叠加规则 | 单状态、新状态完全替换旧状态 |
| 持续时间 | 一直持续到下一次切换（玩家始终处于某个状态） |
| 开局首状态 | 开局第 0s 立即抽一次（玩家无"裸身期"） |
| 切换过渡 | 瞬间替换（无动画，简化实现） |
| **加速** | 移动速度 ×2.0（5 → 10）、加速度同步 ×2.0 |
| **变大** | scale ×1.6、质量 ×2.56（=1.6²） |
| **变小** | scale ×0.6、质量 ×0.36（=0.6²） |
| 与边界耦合 | 出界判定使用「实际半径」——**变大更难死、变小更易死，是核心张力** |
| 视觉反馈 | 玩家本色为底；加速 → 加亮白描边；变大/变小尺寸自带反馈 |
| AI 是否参与 | 否，AI 永远保持 AI 标准状态（见三） |

---

## 三、AI 行为

| 项 | 决策 |
|---|---|
| 外观 | 红色 |
| 速度 | 4（玩家基础 5 的 0.8×） |
| scale | 1.5 |
| mass | 6（**远大于玩家基础 1**，是核心压力源） |
| 加速度 | 25（与玩家一致） |
| 追击逻辑 | 每帧朝当前**最近玩家**直线移动 |
| 状态轮换 | 不参与，AI 永远保持上述标准状态 |
| AI 之间碰撞 | 能碰撞（多 AI 群追时会互相挤压减速） |
| 出界判定 | AI 也整球出界即死，被销毁 |
| 生成节奏 | 第 60s 生成首只；之后每 10s 一只；**无上限、AI 死了不补** |
| 生成位置 | 场地四边随机一点（边界上） |

**平衡参考**（mass 对比）：
- 玩家裸身 mass 1 vs AI 6：被撞必飞
- 玩家变大 mass 2.56 vs AI 6：能拖慢但仍被推
- 玩家变小 mass 0.36 vs AI 6：一击毙命
- 玩家加速 mass 1：跑得过 AI（10>4），但仍被推一下就飞

## 四、胜负

| 项 | 决策 |
|---|---|
| 胜利 | 玩家球数 == 1 的瞬间 → 该玩家胜 |
| 平局 | 玩家球数 == 0 → 平局，AI 不算赢 |
| 检查时机 | 玩家球 `OnDestroy` 时触发胜负检查（不每帧扫描） |
| 计时器 | 正计时（实际是循环倒计时显示），**不参与胜负** |
| AI 计入吗 | 不计入「玩家球数」 |
| 结算时表现 | 立即 `Time.timeScale = 0` 冻结全场 + 弹全屏面板 |
| 面板内容 | 「P1 胜」/「P2 胜」/「平局」+「重开」+「退出」按钮 |

## 五、节奏与 UI

### 计时器

正计时基础上滚动显示**两个独立倒计时**，仅作节奏指示：

| 元素 | 表现 |
|---|---|
| 主元素 | 屏幕顶部中央**大字**：「N 秒后切换状态」（5s 循环） |
| 副元素 | 主元素下方**小字**：「N 秒后 AI」（开局 60s，之后 10s 循环） |

### AI 警告

首只 AI 出现前 **最后 3s** 起：副元素数字变红 + 每秒闪一次（吸引玩家注意阶段切换）。后续 AI 不再警告，纯粹靠副元素自身的倒计时数字传达。

### 配色与状态视觉

| 对象 | 颜色 |
|---|---|
| P1 | 蓝 |
| P2 | 黄 |
| AI | 红 |
| 状态描边（仅加速时显示） | 亮白 |
| 变大/变小 | 不加描边，靠 scale 本身传达 |

### 暂停

ESC 暂停 → 弹出与胜负面板同风格的简单菜单：「继续」「重开」「退出」。
