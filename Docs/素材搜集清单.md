# 碰碰球 美术 & 音效 素材搜集清单

> 本文件用于与协作者分工搜集素材。每项标注**必需 / 可选 / 锦上添花**，可按时间预算自上而下完成。

## 游戏画风建议

- **风格关键词**：极简、几何、对比强、霓虹/扁平二选一
- **整体色调**：暗色场地 + 高饱和球（蓝/黄/红）对比强烈，便于观众一眼分辨阵营
- **分辨率参考**：游戏目标 1920×1080，UI 素材按 2× 准备（即 3840×2160 切图）防止糊

## 一、美术素材

### 1.1 场地 / 背景（必需）

| 素材 | 用途 | 规格建议 | 备注 |
|---|---|---|---|
| 场地背景 | 矩形场地内部地板纹理 | 1920×1080，PNG，可平铺 | 偏暗色，不抢镜；可以是网格地板、霓虹格子、星空、混凝土等 |
| 场地外部背景（可选） | 球被挤出的"虚空"区域 | 同上 | 比场地暗一档，让人一眼看出"那里是出界" |
| 边线装饰（锦上添花） | 场地四条边线 | 9-slice 边框 PNG | 可发光描边，但不要喧宾夺主 |

### 1.2 角色（球）

| 素材 | 用途 | 规格建议 | 备注 |
|---|---|---|---|
| P1 球 sprite | 玩家 1 | 256×256，PNG 圆形透明背景 | **蓝色**主调 |
| P2 球 sprite | 玩家 2 | 同上 | **黄色**主调 |
| AI 球 sprite | AI 红色追击者 | 同上 | **红色**主调，可加齿轮/眼睛纹理强化"威胁感" |
| FastOutline sprite（必需） | 加速状态时的白色光环 | 320×320，圆环透明 | 比球本体大约 1.1×；放在球的子物体上 |
| 球的高光/纹理（可选） | 让球不是纯色平面 | 同球尺寸 | 可单独存为 overlay |

> 实现注意：变大/变小是 **代码动态改 scale**，**不需要**多套不同大小的图。

### 1.3 特效（可选）

| 素材 | 用途 | 形式 | 必要性 |
|---|---|---|---|
| 出界销毁特效 | 球被挤出界时炸开 | ParticleSystem 用的小颗粒贴图 + 颜色配置 | 可选但加分明显 |
| 状态切换闪光 | 每 5s 切换瞬间球身一闪 | 同上 | 可选 |
| AI 生成时的"瞬现"特效 | 红球出现时短促闪光 | 同上 | 可选 |
| 碰撞火花 | 两球相撞瞬间小火花 | 同上 | 锦上添花 |

### 1.4 UI 元素（必需）

| 素材 | 用途 | 规格建议 |
|---|---|---|
| 按钮底图（普通态） | 重开 / 退出 / 继续 | 256×96，9-slice PNG，圆角矩形 |
| 按钮底图（hover 态） | 鼠标悬浮 | 同上，颜色加亮 |
| 按钮底图（按下态） | 鼠标按下 | 同上，颜色压暗 |
| 面板背景 | 胜负面板 / 暂停面板 | 半透明深色覆层 PNG 或纯色 + 透明度 | 占大半屏幕，盖住游戏画面突出弹窗 |
| HUD 计时器底框（可选） | 顶部双倒计时背后的胶囊底框 | 16:9 横长条，半透明 | 让数字在亮色场地上更清晰 |
| 警告闪烁色块（可选） | AI 出现前 3s 屏幕边缘红光 | 全屏边缘渐变红 | 锦上添花，配合 HUD 闪烁 |

### 1.5 字体

| 字体类型 | 用途 | 推荐 | 必要性 |
|---|---|---|---|
| 中文字体 | "P1 胜 / P2 胜 / 平局 / 秒后切换状态 / 秒后 AI / 继续 / 重开 / 退出" | **阿里巴巴普惠体**（免费商用） / **思源黑体**（开源） | 必需 |
| 数字字体 | 倒计时大数字 | **Bebas Neue** / **Oswald** / 中文字体的数字 | 必需 |
| 标题字体（可选） | 胜负面板的"P1 胜！"等大字 | **思源宋体** Heavy 字重 / 装饰中文字 | 可选 |

**实际只用到的字符**（如果用 TMP 生成 Font Asset 只需勾选这些）：

```
0123456789
P1胜P2胜平局秒后切换状态AI继续重开退出暂停
```

数字 + 约 18 个汉字，TMP Font Asset 生成可控制在几 MB 内。

|---|---|---|---|

## 二、音效素材

### 2.1 SFX（必需 / 可选）

| 素材 | 触发时机 | 时长 | 风格建议 | 必要性 |
|---|---|---|---|---|
| 球碰球 | 任何两球碰撞（含玩家-AI、AI-AI） | <0.3s | "咚"或"啵"，撞击力越大音量越大（用 OnCollisionEnter2D.relativeVelocity） | 必需 |
| 球出界销毁 | BoundsKiller 销毁瞬间 | <0.5s | 短促"啵"+ 一点回音 | 必需 |
| 状态切换提示 | 每 5s 切换瞬间 | <0.3s | 中性"叮"或柔和电子音 | 必需 |
| 加速状态启用 | 玩家变为 Fast | <0.4s | "嗖"上升音 | 可选 |
| 变大状态启用 | 玩家变为 Big | <0.4s | 低沉膨胀音 | 可选 |
| 变小状态启用 | 玩家变为 Small | <0.4s | "缩"高音 | 可选 |
| AI 警告 | 第 60s 前最后 3s，每秒一次 | <0.2s | 紧迫的滴滴声 | 必需 |
| AI 生成 | 每只 AI 出现 | <0.5s | 不祥的"轰" / 红色警报音 | 必需 |
| 胜利 | 胜负面板出现 | 1~2s | 上扬的胜利和弦 | 必需 |
| 平局 | 平局面板出现 | 1~2s | 中性下降音 / "失败"提示音 | 必需 |
| UI 按钮点击 | 所有按钮按下 | <0.2s | 干净的"咔哒" | 必需 |
| 暂停 / 恢复 | 按 ESC | <0.3s | 时间冻结/解冻音 | 可选 |

### 2.2 BGM（可选）

| 曲目 | 触发 | 时长 | 风格 |
|---|---|---|---|
| 主背景音乐 | 局内循环 | 1~3 分钟 loop | 紧张感、轻电子或鼓点节拍，能 loop 不突兀 |
| 胜利后乐句 | 胜负面板期间 | 5~10s | 短乐句，结束语 |

**进阶（锦上添花）**：BGM 分段——前 60s 缓慢、AI 进场后切换到密集版。技术上要两段 AudioClip + 在 AISpawner 首次生成时切歌。

## 三、文件交付规格

为减少代码端调整成本，建议统一以下：

- **图片格式**：PNG 透明背景（球、按钮、特效）；JPG 仅用于不透明背景图
- **音频格式**：WAV（短 SFX）或 OGG（BGM）
- **采样率**：44.1kHz / 16bit
- **命名规范**：
  - 美术：`{类别}_{名称}.png`，如 `ball_p1.png`、`btn_restart_normal.png`、`bg_arena.png`
  - 音效：`sfx_{触发}.wav`，如 `sfx_collide.wav`、`sfx_ai_spawn.wav`、`sfx_win.wav`、`bgm_main.ogg`
- **存放位置**（Unity 项目导入后）：
  - `Assets/Art/` 下分 `Balls/` `UI/` `Background/` `VFX/`
  - `Assets/Audio/` 下分 `SFX/` `BGM/`
  - `Assets/Fonts/` 字体源文件 + 生成的 TMP Font Asset

## 五、最小可玩集合（如果时间非常紧）

如果只能搜集**最少必需项**让游戏跑起来不丑：

1. P1 / P2 / AI 三个圆形 sprite（可以是纯色填充圆 + 不同高光）
2. FastOutline 一个白圆环
3. 场地背景一张
4. 中文字体一份（阿里巴巴普惠体）
5. 按钮底图三态（普通 / hover / 按下）
6. SFX：球碰球、球出界、状态切换、AI 警告、AI 生成、胜利、平局、按钮点击 —— 共 8 个
7. BGM 一段循环

总计：5 张图 + 1 张背景 + 3 按钮态 + 1 字体 + 8 SFX + 1 BGM ≈ **3 小时内可完成搜集**。
