# 主菜单与地图系统 - 搭建与接入指南

> 本文档面向「UI 搭建人员 + 策划/美术」。代码已全部写完(见 `Assets/LogicScripts/` 下新增的 11 个脚本)。
>
> 本指南分三部分:
> 1. **§1-§4**: UI 搭建人员 - 搭 MainMenu 场景 + 改 SampleScene
> 2. **§5**: 策划 - 创建 ArenaPreset 地图数据
> 3. **§6**: 美术 - 资源接入位置
>
> 预计耗时:UI 搭建 60 分钟,策划填一张地图 5 分钟。

---

## 0. 系统总览

```
┌─────────────────────┐                      ┌──────────────────────┐
│ MainMenu 场景        │   LoadScene          │ SampleScene 场景      │
│  开始/操作/设置/退出  │ ────────────────────▶│  P1/P2/P3 + AI       │
│  人数选择 / 地图选择  │                      │  ArenaLoader 读取    │
└─────────┬───────────┘                      └──────────┬───────────┘
          │                                              │
          │            GameSession 单例                  │
          │            (DontDestroyOnLoad)               │
          └──────────────────┬──────────────────────────┘
                             │
                  PlayerCount / SelectedArena / 音量
```

**核心思路:**
- `GameSession` 是跨场景的"记事本",MainMenu 把玩家选择写进去,SampleScene 启动时读
- `ArenaPreset` 是 ScriptableObject(右键 Create 创建),策划填数据,完全不写代码
- `ArenaLoader` 在 SampleScene 启动时根据 GameSession 选的地图,应用 ArenaBounds + Instantiate 障碍物

## 1. Build Settings 配置

打开 **File → Build Profiles** (Unity 6+) 或 **Build Settings** (旧版本):

1. 把 `Assets/Scenes/SampleScene.unity` 拖进 Scenes In Build (如果还没有)
2. 新建场景 `Assets/Scenes/MainMenu.unity` (File → New Scene → Save As),也拖进去
3. **把 MainMenu 拖到列表最上面**(索引 0 = 启动场景)

如果场景名跟代码不一致,改 `MainMenuController` 的 `gameSceneName` 字段(默认 `SampleScene`)。

## 2. 搭建 MainMenu 场景

### 2.1 创建 Canvas

打开新建的 MainMenu.unity,删掉 `Main Camera` 之外的所有默认物体(MainMenu 不需要光源)。

Hierarchy 右键 → **UI → Canvas**,设置:

| 组件 | 字段 | 值 |
|---|---|---|
| Canvas | Render Mode | Screen Space - Overlay |
| Canvas Scaler | UI Scale Mode | Scale With Screen Size |
| Canvas Scaler | Reference Resolution | 1920 × 1080 |
| Canvas Scaler | Match | 0.5 |

确认场景里已自动生成 `EventSystem`。

### 2.2 搭建总体层级

按下面层级结构创建空 GameObject 和 UI 节点(右键 → Create Empty / UI → Panel / UI → Button - TextMeshPro):

```
Canvas
├── Background          (UI → Image,铺满,占位用纯色或美术背景图)
├── TitleText           (UI → Text - TextMeshPro,标题"碰碰球")
├── MainPanel           (空 GameObject,主菜单按钮容器)
│   ├── PlayerCountGroup    (空 GameObject,内含人数切换控件)
│   │   ├── Label2P         (TMP Text:"2 人")
│   │   ├── TwoPlayerButton (Button)
│   │   ├── ThreePlayerButton (Button)
│   │   └── CurrentLabel    (TMP Text:"当前: 2 人")
│   ├── MapSelectArea       (空 GameObject,地图选择)
│   │   ├── ListRoot        (UI → Image + HorizontalLayoutGroup,地图按钮自动生成进这里)
│   │   ├── PreviewImage    (UI → Image,选中地图预览)
│   │   └── PreviewName     (TMP Text,选中地图名)
│   ├── StartButton         (Button - TextMeshPro,"开始游戏")
│   ├── HowToPlayButton     (Button - TextMeshPro,"操作说明")
│   ├── SettingsButton      (Button - TextMeshPro,"设置")
│   └── QuitButton          (Button - TextMeshPro,"退出")
├── HowToPlayPanel      (UI → Panel,默认禁用)
│   ├── HelpText            (TMP Text:写控制说明,见 §2.5)
│   └── BackButton          (Button - TextMeshPro,"返回")
└── SettingsPanel       (UI → Panel,默认禁用)
    ├── BgmRow              (空 GameObject)
    │   ├── BgmLabel        (TMP Text:"BGM 音量")
    │   ├── BgmSlider       (UI → Slider, Min=0 Max=1)
    │   └── BgmValueLabel   (TMP Text:"80")
    ├── SfxRow              (空 GameObject)
    │   ├── SfxLabel        (TMP Text:"SFX 音量")
    │   ├── SfxSlider       (UI → Slider, Min=0 Max=1)
    │   └── SfxValueLabel   (TMP Text:"80")
    └── BackButton          (Button - TextMeshPro,"返回")
```

### 2.3 推荐布局参考

> 这些数值是建议起点,UI 设计可以自由调整。

| 节点 | Anchor | Pos X | Pos Y | Width | Height |
|---|---|---|---|---|---|
| TitleText | top-center | 0 | -120 | 1200 | 200 |
| MainPanel | middle-center | 0 | -50 | 1200 | 800 |
| StartButton | top-center (of MainPanel) | 0 | -350 | 360 | 80 |
| HowToPlayButton | top-center | 0 | -450 | 360 | 80 |
| SettingsButton | top-center | 0 | -550 | 360 | 80 |
| QuitButton | top-center | 0 | -650 | 360 | 80 |
| PlayerCountGroup | top-center | 0 | -100 | 800 | 100 |
| MapSelectArea | top-center | 0 | -220 | 1100 | 200 |
| HowToPlayPanel | stretch-all (撑满) | - | - | - | - |
| SettingsPanel | stretch-all | - | - | - | - |

PlayerCountGroup 内 2P/3P 两个按钮横向排列(各 120×60),CurrentLabel 放右侧。

MapSelectArea 的 `ListRoot` 加 `Horizontal Layout Group` 组件(让动态生成的地图按钮自动排开),`Child Force Expand Width/Height` 关掉,`Spacing` 设 12。

### 2.4 创建"地图按钮"Prefab(给 MapSelectController 用)

地图按钮是动态生成的,需要一个 Prefab 模板。

1. Hierarchy 任意位置临时创建 **UI → Button - TextMeshPro**,命名为 `MapButton`
2. 设置 Width=160, Height=120
3. 在 Button 子节点 `Text(TMP)` 里把 Font Size 改为 28,Anchor 改为 bottom-center,Pos Y = 12(文字放下方)
4. 给 Button 加一个 Image 子节点 `Preview`(Anchor stretch-all,Size 留 -40 padding),作为地图缩略图。**注意:不要勾上 Raycast Target**(避免阻挡 Button 点击)
5. 把 `MapButton` 拖到 `Assets/Prefabs/` 文件夹下,变成 Prefab
6. 删掉 Hierarchy 里的临时实例

> 脚本会自动找 Prefab 上的 `TMP_Text` 填地图名,找子 `Image` 填缩略图。

### 2.5 HowToPlayPanel 文本内容建议

```
玩法说明

· 把对手挤出场地外即获胜
· 状态轮盘会每隔 N 秒切换全场效果(快/大/小)
· 60 秒后会出现红色 AI 球,撞死你也算输
· 道具掉落:加速/变重/反向(60% 持续时间)

操作

· 玩家 1: WASD 移动
· 玩家 2: 方向键 移动
· 玩家 3: IJKL 移动
· ESC: 暂停 / 继续
```

### 3.6 (可选) UIFader / ButtonHoverEffect

让 UI 更生动:

- **UIFader**: 挂到 `HowToPlayPanel` 和 `SettingsPanel`(会自动加 `CanvasGroup`),激活时淡入。默认参数即可。
- **ButtonHoverEffect**: 挂到任意 Button(Start/HowToPlay/Settings/Quit、地图按钮 Prefab、Back 按钮等),hover 时放大 1.08x,按下时缩 0.95x。

把 ButtonHoverEffect 挂在 `MapButton.prefab` 上,所有动态地图按钮自动带 hover 反馈。

### 3.7 默认禁用 HowToPlayPanel / SettingsPanel

选中这两个 Panel,Inspector 顶上 GameObject 勾去掉(MainMenuController 启动会自动 ShowMain)。

## 4. 改造 SampleScene

打开 `Assets/Scenes/SampleScene.unity`。

### 4.1 加 ArenaLoader

1. Hierarchy 右键 → Create Empty,命名 `ArenaLoader`
2. 加 `ArenaLoader` 脚本组件
3. **必须创建一个背景节点**(给 ArenaLoader 用):
   - 在场景里新建 `Background` GameObject,加 `Sprite Renderer` 组件
   - 把 Sorting Order 设为 -10(放最底)
4. 创建一个空 GameObject `ObstacleParent`(障碍物的父节点,运行时挂载)
5. 接线 ArenaLoader:

| 字段 | 拖什么 |
|---|---|
| Arena Bounds | 现有的 `ArenaBounds` GameObject |
| Background Renderer | `Background` 的 SpriteRenderer |
| Obstacle Parent | `ObstacleParent` |
| Fallback Preset | 留空 / 拖默认地图(直接 Play SampleScene 调试时用) |

### 4.2 加 PlayerRoster

1. Hierarchy 创建 `PlayerRoster` GameObject
2. 加 `PlayerRoster` 脚本
3. 接线:

| 字段 | 拖什么 |
|---|---|
| Player1 | 场景里的 P1 GameObject |
| Player2 | 场景里的 P2 GameObject |
| Player3 | 场景里的 P3 GameObject(如果还没有 P3,临时留空) |

> 如果 P3 还没放到场景里:用 `AIBall.prefab` 复制改一个 P3,挂 `Player3Controller`,放进 Hierarchy,再接到 PlayerRoster.Player3 字段。

### 4.3 验证 GameSession 自动创建

不需要手动挂 `GameSession`。MainMenuController.Start 会调 `GameSession.Ensure()` 自动生成一个 DontDestroyOnLoad 单例。SampleScene 启动时如果没有(比如直接 Play SampleScene 调试),`ArenaLoader` 会用 Fallback Preset。

## 5. 策划:创建 ArenaPreset 地图

### 5.1 创建第一张地图

1. 在 `Assets/` 下创建文件夹 `Resources/ArenaPresets/`(**必须放这个路径**,脚本会自动加载)
2. Project 视图右键 → **Create → PongPongPong → Arena Preset**
3. 命名,比如 `Arena_Default.asset`,在 Inspector 填字段:

| 字段 | 含义 | 推荐值 |
|---|---|---|
| Display Name | 菜单显示的中文名 | "标准" |
| Preview Sprite | 菜单缩略图(美术给) | 留空也行 |
| Bounds Min | 场地左下角(world unit) | (-8, -4.5) |
| Bounds Max | 场地右上角 | (8, 4.5) |
| Border Color | 边框线颜色 | 红色半透 (1, 0.3, 0.3, 0.55) |
| Background Sprite | 场地背景图 | 美术给 |
| Background Tint | 背景叠加色 | 白色 |
| Obstacles | 障碍物列表 | 留空 = 空场 |

### 5.2 多个地图建议预设

| 文件名 | 名称 | Min | Max | 特色 |
|---|---|---|---|---|
| Arena_Default | 标准 | (-8, -4.5) | (8, 4.5) | 16:9 默认 |
| Arena_Narrow | 窄长 | (-10, -3) | (10, 3) | 横向拥挤 |
| Arena_Square | 方形 | (-5, -5) | (5, 5) | 撞击更密集 |
| Arena_Pillar | 中柱 | (-8, -4.5) | (8, 4.5) | 中心加一个柱子(填 Obstacles) |

### 5.3 添加障碍物(Obstacles)

每个 Obstacle 条目:

| 字段 | 含义 |
|---|---|
| Prefab | 障碍物 Prefab(必须带 Collider2D / Rigidbody2D=Static) |
| Position | 障碍物世界坐标(相对场地中心 0,0) |
| Rotation | Z 轴旋转(度) |
| Scale | XY 缩放(填 0,0 等同 1,1) |

**先创建一个障碍物 Prefab:**
1. Hierarchy 右键 → 2D Object → Sprites → Square,命名 `Obstacle_Box`
2. 加 `BoxCollider2D`(默认即可)
3. 不加 Rigidbody2D(让它静态),或加 Rigidbody2D Body Type=Static
4. SpriteRenderer 颜色调成深灰
5. 拖到 `Assets/Prefabs/` 变成 Prefab
6. 删除 Hierarchy 里的实例

然后在 ArenaPreset 里 Obstacles 加一行,Prefab 拖 `Obstacle_Box`,Position 写 (0, 0),Scale 写 (2, 0.4),就是横在中间的一条挡板。

## 7. 跑通流程验收

1. **Build Settings** MainMenu 在最上面
2. 按 Play(自动进 MainMenu)
3. 点 2 人 / 3 人 → CurrentLabel 文字变化、按钮高亮切换
4. 点地图按钮 → 预览图 / 名字更新,选中按钮高亮
5. 点设置 → 滑条拖动 → 数字更新(回主菜单再进还在,因为 PlayerPrefs)
6. 点操作说明 → 显示文本,点返回 / 按 ESC 返回
7. 点开始 → 加载 SampleScene → 球数量符合人数选择、场地大小符合选的地图
8. 游戏结束后点重开 → 重进 SampleScene(保留 GameSession 单例,所以人数/地图保持)
9. 想换地图:游戏中按 ESC 退出,SceneManager 回 MainMenu(目前还没做此入口,如有需要在结算面板加"回主菜单"按钮即可)

## 8. 常见问题

**Q: Play 时报错 "GameSession not found"**
A: 不会,`GameSession.Ensure()` 自动创建。如果你想完全控制,可以在 MainMenu 场景里手动创建一个 GameSession GameObject 挂脚本。

**Q: 地图按钮没出来**
A: 检查 `Resources/ArenaPresets/` 路径必须正确(注意大小写)。或者 MapSelectController 的 Presets 字段手动拖几个 .asset 进去(留空才会走 Resources 自动加载)。

**Q: 切到 SampleScene 后场地大小没变**
A: 看 ArenaLoader 是否挂上、字段是否接好,以及 MainMenu 里有没有真的选中地图(预览面板有显示名字才算选上)。

**Q: 3 人模式 P3 球出现在 (0,0)**
A: 是 P3 在 SampleScene 里默认位置就在原点。在 Hierarchy 把 P3 移到你想要的初始位置,或者 PlayerRoster 里改用 Instantiate 模式(本指南没做,简单方案是把 P3 放在场景里固定位置)。

**Q: ButtonHoverEffect 跟 Button 的 Color Transition 冲突**
A: 关掉 Button 组件的 Transition(改为 None),让 ButtonHoverEffect 接管视觉反馈。或者保留 Color Transition 用于颜色变化、ButtonHoverEffect 用于缩放,两者不冲突。
